# Tech Stack

## Core
- React 18 (`react`, `react-dom`)
- Create React App (`react-scripts@5`)
- React Router (`react-router-dom@6`)

## Animation / Motion
- GSAP (`gsap`)
- Framer Motion (`framer-motion`)
- Split text animation (`split-type`)

## UI / Media
- Font Awesome React packages
- MediaPipe + `react-webcam` (experimental/trial features)

## Build / Dev model
- CRA dev server (`npm start`)
- Live reload in development
- Typical entry: `src/App.js`
- Shared command/animation helpers: `src/Commands.js`

## Notes
- Project currently runs with lint warnings, but app compiles.
- CRA stack is legacy but stable enough for this portfolio workflow.
